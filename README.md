# VALEBOUND — Unity Project

A complete 3D open-world action-adventure game for Android, built on
Unity 2022.3 LTS + URP, made entirely from CC0 assets (Kenney + Quaternius +
OpenGameArt) and original C#.

**Game:** VALEBOUND — you are Rin Ashford, a courier saving your grandfather's
guild from a corporate land-grab across Aurora Valley: **7 settlements** (3 core
cities + village + 4 biome cities), a 6 km × 6 km world with cherry-blossom,
desert, snow and volcano regions, **17 vehicles** (cars, trucks, emergency,
2 bikes) with a **14-color paint shop**, on-foot exploration with vehicle
enter/exit anywhere, 10 story missions + 6 biome side missions, endless courier
and **taxi passenger** jobs, races, daily challenges, stunt air-time rewards,
collectibles, day/night, biome weather (falling petals, snow, embers, dust)
and full mobile UI.

## One-time setup

1. **Install Unity 2022.3 LTS** (exact: `2022.3.62f1`) via Unity Hub with
   **Android Build Support** — check *OpenJDK* and *Android SDK & NDK Tools*.
2. Open this folder (`game/`) as a project. First import takes a few minutes.

## Build the world & play (in editor)

The world is **generated by editor tools** (deterministic, seeded) — this keeps
the repo small and the build reproducible. Run once, in this order:

| Step | Menu item | What it does |
|---|---|---|
| 1 | `VALEBOUND → Configure Project` | import settings, ground textures (grass/rock/sand/snow/ash), tags/layers |
| 2 | `VALEBOUND → Build Prefabs` | player, pedestrian + taxi NPCs, mission givers, audio registry |
| 3 | `VALEBOUND → Build Expanded Vehicle Roster` | 17 vehicles (incl. 2 bikes with rider rigs) + VehicleDefs |
| 4 | `VALEBOUND → World Builder → GENERATE WORLD` | 6 km terrain with 4 biomes, 7 settlements, ring highway, roads, forests, POIs, shards, races, parked cars, biome zones, NavMesh, minimap |
| 5 | `VALEBOUND → Build Data Assets` | 10 story + 6 biome side missions, achievements, garage roster |
| 6 | `VALEBOUND → Build Scenes` | UI canvas wiring (incl. paint shop + daily challenges), Boot + Main scenes, build settings |

Or run the whole pipeline headless:
`VALEBOUND → Build → Prepare Project (full pipeline)`.

> **Order matters:** `Build Scenes` adds the UI/spawn **into the open world scene**
> — it no longer creates a fresh scene, so it can't wipe a generated world. But
> `World Builder` must run **before** `Build Scenes` (or just use the full pipeline,
> which runs everything in the correct order).

Then open `Assets/VALEBOUND/Scenes/Boot.unity` and press **Play**.

## Android builds

```bash
cd release
./build_android.sh apk    # debug APK  -> build/VALEBOUND-debug.apk
./build_android.sh run    # build + install on connected device
./build_android.sh aab    # signed release AAB for Google Play
```

Release signing: create a keystore once
(`keytool -genkey -v -keystore release/valebound.keystore -alias valebound ...`),
set it in *Project Settings → Player → Publishing Settings*, and edit the
password variables at the top of `build_android.sh`.

## Performance architecture (summary)

- Static world geometry (cities, roads, nature) flagged static → static batching.
- Traffic/pedestrians/NPCs pooled with hard caps scaled by device tier
  (`PerformanceGovernor`: RAM/cores detection + rolling frame-time governor that
  steps quality down and (once) back up).
- ASTC 6x6 texture compression for Android, mip streaming on.
- 3 quality tiers (Low/Medium/High): shadows, render scale (URP), LOD bias.
- 6 km × 6 km terrain with ring mountains, flat city pads, 4 biome regions
  (volcano cone, frost plateau, dune bowl, blossom meadow).
- Pooled audio voices with distance culling; compressed OGG/Vorbis.

## Save system

JSON at `Application.persistentDataPath`:
`valebound_autosave.json`, `valebound_slot0..2.json`, `settings.json`.
Atomic writes (temp + rename). Autosave after every mission, paint change and
on pause→menu. Saves include vehicle paints, daily challenge state, and story
vehicle unlocks.
